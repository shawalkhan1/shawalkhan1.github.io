ML Foundations / Reinforcement Learning

Learning algorithms from first principles

From-scratch implementations of neural networks, AlphaZero, and neuroevolution to understand how learning systems work internally.

Shawal Latif · PyTorch and Java

Implementation projects

Problem My contribution Approach Evidence Limitations Next questions

The problem

Implementing the learning loop makes assumptions in an algorithm concrete: how gradients move through a network, how search informs a policy, and how evolution changes a model.

My contribution

My implementations include AlphaZero for Connect 4, a neural network with backpropagation for MNIST, and NEAT for CartPole and Flappy Bird.

How it works

Implement the learning signal.

A neural network with backpropagation was implemented from scratch and reached a reported 95% on MNIST. The current portfolio summary does not specify the split or complete evaluation settings.

Connect policy learning to search.

The AlphaZero implementation uses Connect 4 as its environment. The project explores reinforcement learning and search through implementation rather than relying only on a high-level library.

Explore how structure can evolve.

The NEAT implementations target CartPole and Flappy Bird, connecting neuroevolution to interactive environments.

Implementation overview. Algorithm descriptions are separate from measured benchmark claims.

Evidence & current status

The MNIST network has a reported 95% result in the original project summary. The AlphaZero and NEAT work is described by its implementation targets; no comparative benchmark is presented here.

Limitations

Evaluation settings and source links are needed before treating these summaries as reproducible benchmark results.

Next questions

What do these implementations reveal about computation, sample efficiency, and the tradeoff between general learning systems and task-specific design?
