Computer Vision / Reinforcement Learning

NBA-3D & Basketball-RL

Connecting multi-view reconstruction, differentiable simulation, and behavior learning from basketball data.

Shawal Latif · PyTorch

Technical project

Problem My contribution Approach Evidence Limitations Next questions

The problem

Learning from real-world movement connects perception with decisions. This project explores how video-based reconstruction and a differentiable environment can support that connection.

My contribution

I worked on 3D reconstruction of NBA players from multi-view video using a differentiable renderer, alongside a differentiable 2D basketball reinforcement-learning environment.

How it works

01 Multi-view video
02 Differentiable rendering
03 Behavior cloning
04 Reward fine-tuning

The reinforcement-learning component is behavior-cloned from real NBA data and then fine-tuned using rewards. The 3D reconstruction and 2D environment are distinct parts of the project.

Evidence & current status

The implementation spans computer vision, differentiable rendering, and reinforcement learning in PyTorch. Reconstruction quality and learned behavior need separate evaluation.

Limitations

Without a documented dataset split, evaluation protocol, and results, this summary should be read as an implementation overview.

Next questions

How can the learned behavior be evaluated separately from reconstruction quality, and how does differentiability change the optimization choices?
